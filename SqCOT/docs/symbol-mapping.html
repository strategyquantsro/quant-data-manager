01 / Quick startAttach, inspect, explore

  1. Copy the release's MQL5 folder into the intended terminal. Use File → Open Data Folder in MT5 to locate the destination. Refresh both Indicators and Expert Advisors in Navigator after copying.
  2. Restart SqCOTService to load the new executable. Enter your Quant Data Manager key once in QDM Data License and keep the download settings. The service creates the shared CSV automatically, then fills it with every market in the validated local dataset.
  3. Attach SqCOT. Its default CotIdentifier is AUTO / 52W. XAUUSD and GOLD resolve to GC; USDJPY resolves to 6J with an INV badge.
  4. Click the compact mapping row below the attribution. The expanded inspector appears on the main chart with an opaque background. Use Auto, 52W / 156W, Validate / load, search, the No aliases filter and page arrows.
  5. Clicking a market in the inspector or heatmap selects it manually for this chart. The minute timer does not override that choice. Click Auto to follow the chart symbol again.

The compact row and tooltip show the source rule, quote orientation and errors. CSV location writes the full shared path to the Experts log and exposes it in the button tooltip. Mapping controls appear when ShowUpdatePanel is enabled.

SQX chart interface

SqCOT now defaults to AUTO; explicit first inputs such as GC_52W still select the exact series. The first two input positions and all five data buffers remain unchanged. SqCOTAuto remains as a compatibility alias using the same implementation. SQX exports that pass additional indicator inputs require individual validation. Chart preferences are specific to the broker server, chart symbol, input mode and UIInstance. Timeframe changes keep the saved choice.

First start before data exist

Default aliases are embedded in the executable. No external CSV is required to recognize common markets. A missing catalog produces SERIES_UNAVAILABLE until the licensed service has downloaded data. The update button can bootstrap the archive without a successful map. No unrecognized chart silently switches to Euro COT.

02 / AdministrationOne editable file

FILE_COMMON\StrategyQuant\COT\config\symbol-map.csv

FILE_COMMON is MT5's shared Files directory, including for portable terminals. Use CSV location to find the actual Windows path. Sharing across different Windows users, hosts or VPS machines requires an explicit file transfer.

FilePurpose
symbol-map.csvUser-editable UTF-8 rules; service creates it if absent.
catalog.csvGenerated exact series IDs, market IDs, horizon, provider report marker, availability and generation. Removed series remain marked unavailable.
active/<hash>.csvValidated content-addressed revisions for recovery.
active.dat / active-info.datLast valid revision pointer and schema/resolver/source provenance.
config/symbol-map.example.csv and symbol-map.schema.json in ZIPReference files only. Do not copy the example over custom runtime rules.

The catalog covers every series in the provider's validated metadata, not only favorites or RequiredSeries. Its provider report marker means the source does not supply a more specific type here. Unknown identifiers retain their full identity. Only the known _52W / _156W suffixes are grouped. New markets get blank aliases; existing names, notes, disabled rules and broker exceptions are preserved.

Readers validate local configuration at most once per minute; unchanged content is cached. Validate / load forces a local check. Configuration checks do not download COT data. Service synchronization is separate from weekly network scheduling.

Editing safely

Use a UTF-8 text/CSV editor with semicolon delimiter. Save the entire file, then Validate / load. The service serializes its writes with an OS lock, compares the original content immediately before replacement, and defers when it detects another edit or a locked file. External editors do not honor the service lock: avoid saving an old editor copy over a newer file, and reload when the editor reports an external change. Runtime rules are outside dataset generations and survive data updates.

03 / Exact matchingExplicit rules, predictable results

schema;market_id;display_name;broker_server;aliases_direct;aliases_inverse;enabled;note
1;GC;Gold;*;XAUUSD|GOLD;;1;USD gold
1;GC;Gold;Example-Demo;XAUUSD.a|GOLD.cash;;1;Broker-specific names
1;6J;Japanese yen;*;;USDJPY;1;Inverse quotation
1;ZB;Treasury bonds;*;;;1;No approved CFD alias

Example-Demo is illustrative; replace it with the exact MT5 server name. Aliases match the complete symbol, ignoring case. Suffixes and prefixes must be listed explicitly. Regex and wildcard aliases are unsupported. Multiple aliases use a vertical bar. Standard CSV quoting supports semicolons, newlines and doubled quotes. Limits are 256 KiB, 4,096 characters per cell and 8,192 records including the header.

  1. An explicit SeriesId bypasses mapping.
  2. A matching alias for the exact broker server takes precedence over the global * row.
  3. A disabled matching broker alias blocks the global fallback.
  4. Duplicate aliases within a scope, including direct/inverse conflicts, invalidate the whole configuration. Missing horizons never substitute another horizon.
INV is a quote relationship. USDJPY is inverse to the 6J futures quotation. This does not invert CPI/CTI, compute 1 − value, or create a buy/sell instruction. All five raw values stay unchanged.

Cross pairs such as EURGBP do not receive a synthetic COT series. Brent is not mapped to WTI. Broker contract descriptions, basis and currency metadata are available in the tooltip for inspection; they do not create heuristic matches. Verify broker-specific contracts before adding their aliases.

04 / Algo interfaceResolve, check, then use data

#include <SqCOTClient.mqh>
CSqCOTClient cot;
// In OnInit, outside the tester:
cot.OpenAutoLive(_Symbol, AccountInfoString(ACCOUNT_SERVER), 52);
// In OnTick:
SqCOTSnapshot data;
CotMapResult mapping;
cot.Mapping(mapping);
if(cot.ReadLatest(data) && cot.CanTrade(data)) {
   // Original data.values[0..4]; apply your strategy here.
}

See SqCOTAutoLatest.mq5 for a complete read-only EA. Mapping exposes status, market, series, orientation, rule source, configuration hash and diagnostics. Initial missing data/configuration are recoverable: the client binds its first valid resolution when it becomes available. Once bound, a changed configuration hash or resolved series closes readiness with CONFIG_CHANGED. Review the change and explicitly call OpenAutoLive again to accept it. Even a note edit or an appended market changes the file hash. No mapping operation opens, closes or modifies a trading position.

Mapping errors close both data reads and CanTrade. Explicit OpenLive / OpenSnapshot clients do not depend on this configuration. A resolved series is automatically registered with the service; no manual RequiredSeries edit is needed for that client.

iCustom: opt-in AUTO with the same eleven buffers
int h = iCustom(_Symbol, PERIOD_H1, "SqCOTData",
                "AUTO", "UTC+120", "", true, 52, "");

The first four inputs are unchanged. Appended inputs are AutoHorizonWeeks (52 by default) and AutoBrokerServer (empty uses the current account server). Supply the correct historical broker time profile; UTC+120 is only an example. Buffers retain API 1 semantics and raw values. Mapping failure clears readable data, with INVALID in buffer 8. Recreate an AUTO handle intentionally after accepting a configuration change. An iCustom buffer alone does not replace the SDK freshness/readiness checks documented in the main guide.

05 / Immutable runsFreeze mapping with your data

  1. Run SqCOTExportSnapshot on the CFD symbol you intend to test. Choose a new SnapshotId. IncludeMapping defaults to true; it freezes CSV, resolver version, source-metadata hash, exact symbol, exact broker server and descriptive symbol metadata.
  2. Use the same symbol and exported server in OpenAutoSnapshot(symbol, server, weeks, snapshotId, brokerProfile). Or pass AUTO, broker profile, snapshot ID, true, horizon and the exported broker server to SqCOTData.
  3. The client verifies hashes and pins map, PIT data, runtime policy and broker profile for the entire run. Live CSV edits cannot affect the running test. Export a separate snapshot for a different symbol/server.

AUTO without a valid mapping snapshot fails initialization in the tester. The visual SqCOT is for chart exploration; strategies should use SqCOTData or the SDK for strict snapshot tests. Older explicit-series snapshots remain supported without mapping files. Export with IncludeMapping=false if you only need an explicit-series snapshot while repairing a broken live CSV.

Pinning does not invent historical publication timestamps. The existing locally observed point-in-time restrictions still apply; see Time and availability.

06 / DiagnosticsKeep custom rules recoverable

Status / situationAction
UNMAPPEDAdd the exact approved alias, or select a market manually.
DISABLEDInspect the matching scoped rule. No global fallback is used.
SERIES_UNAVAILABLECheck service/data availability and the requested horizon.
CONFIG_INVALIDRepair the reported record/column. Conflicting aliases include AMBIGUOUS in the diagnostic. Existing visual curves may remain with the error displayed; AUTO trading readiness is closed.
CONFIG_CHANGEDReview the new revision, then intentionally reopen the SDK client or indicator handle.
Missing CSVService restores the last valid revision; on a genuinely new installation it creates embedded defaults.
Damaged recovery revisionRestore a verified backup. The service does not silently replace prior custom rules with defaults.

An invalid existing CSV is never treated as a missing file and overwritten. To roll back explicitly, copy the validated revision named by active.dat over symbol-map.csv, then Validate / load. Keep another copy of the malformed file if you need to recover unfinished edits. Service error notifications use the existing popup/push settings and are deduplicated; unchanged CSV does not trigger repeated alerts.

After changing a mapping, confirm the chart symbol, selected COT series and horizon before using its values in a strategy.
